# Panneau PR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une colonne Herdr à droite, ouverte et fermée par `ctrl-shift-g`, qui montre les PR ouvertes de la branche du terminal focalisé : statut, approbations, relecture demandée, CI, Sonar, fils et commentaires, description, et les boutons Relire / Retours.

**Architecture:** Mod `mods/pr-panel/` : `pr.js` (règles pures), `load.js` (choix du terminal suivi et appels `git`/`gh`, `run` injecté), `sections.js` (dessin de chaque section), `main.js` (cycle de vie de la vue). Les morceaux purs de start-work dont il a besoin (`ghCommand`, `GH_AS`, `githubRepo`) passent dans `mods/start-work/profile.js`, testé sous node ; `lastVerdicts` de `github.js` est exporté.

**Tech Stack:** gpui-kit / herdr (`gpui-kit.d.ts`, `herdr.d.ts` à la racine de `~/.config/herdr-app`), `gh` (JSON + GraphQL), tests `node <fichier>.test.js` avec `node:assert/strict`.

**Spec:** `docs/superpowers/specs/2026-11-27-pr-panel-design.md` · Glossaire : `docs/domaine.md`, contexte « Panneau PR ».

## Découpage en PR

Une seule PR (`feat/pr-panel`), une seule story (P1) : moins de 15 fichiers, et les boutons ne servent à rien sans le panneau.

## Review Focus

1. Auteur supprimé (`author: null`, compte « ghost ») dans un avis, un fil ou un commentaire : affiché « ghost », pas de plantage. → `pr.test.js` `auteur absent`.
2. Fil sur une ligne disparue (`line: null`, `originalLine: 12`) : `fichier:12` ; ni l'un ni l'autre : `fichier`. → `pr.test.js` `fil sans ligne`.
3. Avis approuvé sans texte (`body: ""`) : pas de ligne vide dans les commentaires hors fil. → `pr.test.js` `avis sans texte`.
4. `statusCheckRollup` nul ou check sans `name` ni `context` : ignoré sans planter. → `pr.test.js` `sans check`.
5. Branche avec `/` ou `#` (`feat/a#1`) : passée en un seul argument à `gh` (pas de shell). → `load.test.js` `branche spéciale`.

### Task 3 : Règles de la PR (`pr.js`)

§2 R2, §4 P1 (nominaux, combinés).

**Files:**

**Interfaces:**
- Consumes: `lastVerdicts`, `myPrMeta`, `isPending`, `prStatus`, `APPROVALS_FOR_QA` (`../start-work/github.js`).
- Produces:
  - `PR_FIELDS = "number,title,url,isDraft,author,additions,deletions,changedFiles,body,reviews,statusCheckRollup"`
  - `checkState(check) -> "ok" | "ko" | "running"` — sur `conclusion || state || status` : `SUCCESS/NEUTRAL/SKIPPED` → ok ; `FAILURE/ERROR/CANCELLED/TIMED_OUT/ACTION_REQUIRED/STARTUP_FAILURE` → ko ; reste → running.
  - `checksOf(rollup) -> { sonar: { state, url } | null, ci: { text, state } | null, open: [{ name, state, url }] }` — nom = `name ?? context` (check sans nom ignoré) ; Sonar = nom matchant `/sonar/i`, pire état (ko > running > ok), url du pire ; `ci.text` = parties non nulles de `"n en échec"`, `"n en cours"`, `"n ✓"` jointes par `" · "`, `ci.state` = pire état ; `open` = hors Sonar, ko puis running ; url = `detailsUrl ?? targetUrl ?? null`.
  - `isBot(author) -> boolean` — `__typename === "Bot"` ou login finissant par `[bot]`.
  - `PR_THREADS_QUERY` — `query($owner:String!,$name:String!,$number:Int!)` : `viewer{login}`, `repository.pullRequest{ reviewThreads(last:100){nodes{isResolved path line originalLine all:comments{totalCount} first:comments(first:1){nodes{author{__typename login}}} last:comments(last:1){nodes{author{login}}} comments(last:20){nodes{author{__typename login} body}}}} comments(last:50){nodes{author{__typename login} body}} reviews(last:50){nodes{author{__typename login} body}} }`.
  - `feedbackOf(response, mine) -> { me, threads: [{ where, pending, resolved, comments: [{ author, body, bot }] }], notes: [{ author, body, bot }], pending }` — `where` = `path:line`, `path:originalLine` ou `path` ; ordre : `mine` → en attente (`isPending(t, me)`) d'abord, sinon non résolus d'abord, ordre d'origine conservé à égalité ; `notes` = commentaires puis avis dont `body.trim()` non vide, sauf ceux de `me` ; auteur absent → `"ghost"` ; lève `Error("réponse GraphQL sans pullRequest")` si `data.repository.pullRequest` manque.
  - `panelOf(pr, { me, reviewAsked, feedback }) -> { number, title, url, status, diff, approvals, reviewers, mine, reviewAsked, checks, feedback, body }` — `mine` = logins égaux casse ignorée ; `approvals` = `mine ? myPrMeta(reviews) : "<nb APPROVED>/2"` ; `reviewers` = `[...lastVerdicts]` sans l'auteur, en `{ login, state }` ; `reviewAsked` = `!mine && reviewAsked` ; `diff` = `"+<additions> −<deletions> · <changedFiles> fichiers"` ; `body` = `body.trim()` ou `null` ; `feedback` passé tel quel (peut être `null`).
